# nuri アプリ概要

nuriは、お手本のメイクを自分の顔で再現するためのアプリです。メイクレシピを選び、カメラに映る顔に重ねたガイドで、手順ごとに塗る位置と色を確認できます。

画面の正本は[Figma「実装plan」](https://www.figma.com/design/dwoWsLmVBU5c0Hx0vlVWua/?node-id=21-11426)です。[要件定義](requirements.md)に画面番号・採用範囲・未決事項を、[アーキテクチャ](architecture.md)に実装方式をまとめています。

## 現在使える機能

- メイク（①〜⑦・⑩）では、レシピを探し、使うコスメと手順を確認する。対応する開発ビルドではライブ顔追跡と塗る範囲の表示を使える。
- 提案（⑬・⑭）では、カメラや選んだ写真から顔タイプなどを診断し、おすすめのレシピを確認する。
- 投稿（⑫）では、録画した動画や端末から選んだ動画から手順書を作り、区間・色・塗る範囲を編集してレシピを公開する。
- マイ（⑰・⑰-2）では、投稿したレシピやお気に入りを見て、プロフィールを編集する。Google連携とパスキー管理はプロフィール設定の「アカウント」にある。利用可能なログイン方法は[認証の設定](auth.md)を参照する。

## データの境界と未決事項

- ライブ顔追跡・AR描画・写真診断は端末内で処理する。
- ⑫-3では、利用者が録画の解析に同意して「送る」を選ぶと、APIを経由してGeminiへ動画を送る。APIは解析用の動画を永続保存しない。レシピを公開するときは手順とサムネイルなどを送り、動画は送らない。プロフィール写真は「保存する」を選んだ場合に送る。[プライバシー要件](requirements.md#5-非機能要件)を参照する。
- SNSのURL取り込み（④）は準備中の案内を表示する。外部投稿の取得方法と権利条件は[要件定義の未決事項](requirements.md#9-sns投稿の取得と権利の判断)で扱う。

## 検証の範囲

初期の技術検証では、端末上の顔追跡（P1）と顔に合う塗布範囲の表示（P2）を優先した。30fps・左右約30度・異なる顔型5人は当時の評価目安であり、[仮想端末での測定・目視記録](requirements.md#12-検証の状況)とは区別する。対象機能と端末に応じた確認方法は[検証手順](testing.md)を参照する。

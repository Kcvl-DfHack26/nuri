# nuri アプリ概要

この文書は、2026年11月6日の要件資料を基に、リポジトリ作成時点の理解をまとめたものです。技術候補や成功目安は検証前の案です。Figma「実装plan」（旧称「Plan A」）との対応、優先度、画面ごとの要件、AR表示の方式は[要件定義](requirements.md)にまとめています。

## 解決する課題

SNSのメイク動画を見ても、お手本と自分の顔の形が違うため、塗る位置や量を判断しにくい。メイク中は手もふさがる。nuriは、レシピの手順を自分の顔に合わせて示し、再現を助けます。

## 最初の利用者体験

1. 一覧・検索やSNS投稿からメイクレシピを選ぶ。
2. レシピの各手順で、インカメラの顔に塗る範囲と色を重ねて見る。
3. 使うコスメと塗り方を確認し、「次へ」「戻る」で進める。
4. 全手順を重ねた完成形を見て、メイク前と比較する。

要件資料ではF1〜F4を初期範囲とし、SNSからの取り込み（F1-2）も必須としています。塗れ具合の自動判定、音声・顔ジェスチャー操作、顔に合う提案、成分検索、色味の試し塗り、投稿、アカウントは追加候補です。18画面のUI一覧は全体構想であり、すべてを最初の実装範囲とはしません。

## 最優先のPoC

- **P1 顔追跡:** 端末上で顔の特徴点を検出し、動きに追従できるか。案として中位のスマートフォンで30fps以上、顔を左右30度向けても外れないことを目安とします。
- **P2 範囲の重ね表示:** 特徴点からの相対位置で眉・チーク・シェーディングを描き、顔型が違っても範囲がずれないか。案として5人以上で目視確認します。

最初は眉のレシピ1つとAR手順画面を動かし、P1・P2を確認します。その後、SNS投稿から手順とコスメを取り出すP3を検証します。

## 初期の境界と未決事項

- 顔の映像は端末内で処理し、利用者が明示的に保存・投稿を選んだ写真だけを送信する方針です。
- iOS・Androidのスマートフォンを想定します。Expoスターターは出発点ですが、顔追跡とAR描画の実装方法はPoCで決めます。
- SNS投稿の取得・解析方法、投稿者の権利、商品・成分データの入手先は未決です。
- 完成画面の「お手本との近さ」は、算出方法が決まるまで実測値として表示しません。自動判定自体は追加候補です。
- 端末上の顔追跡、AR表示、完成比較が中心です。サーバーはレシピ・商品・投稿・SNS取り込みを担当する構想です。

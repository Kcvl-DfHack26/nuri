# Sample recipes

Photos for the twelve editorial recipe templates (①⑤) and two generic cosmetic categories. They are the image fills of the team's Figma design file [Plan A](https://www.figma.com/design/dwoWsLmVBU5c0Hx0vlVWua/) (node 21:11426), exported with the Figma MCP server for the Plan A screens (#5, 2026-11-07) and copied here from `apps/mobile/assets/plan-a`. The API serves these files without an external image service. Recipe techniques and color families are documented in [makeup-recipes.md](../../../docs/makeup-recipes.md); the photos illustrate the looks and do not prove a product or shade.

- `fox.jpg`, `round.jpg`, `cat.jpg`, `long.jpg`, `office.jpg`, `korean.jpg`: ① ホーム（全体メイク） recipe cards
- `brow-*.jpg`: ③ 部位別一覧 brow styles, each a cell of Plan A's brow style sheet (`apps/mobile/assets/plan-a/parts/brow-styles.jpg`)
- `product-brow-pencil.jpg`, `product-cheek.jpg`: ⑤ レシピ詳細の道具の種類を示す画像

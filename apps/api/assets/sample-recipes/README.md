# Sample recipes

Photos for the development sample recipes (①⑤) and their cosmetics. They are the image fills of the team's Figma design file [実装plan, formerly Plan A](https://www.figma.com/design/dwoWsLmVBU5c0Hx0vlVWua/) (node 21:11426), exported with the Figma MCP server for the Plan A screens (#5, 2026-11-07) and copied here from `apps/mobile/assets/plan-a`. Recipe titles, authors, tags, durations, sources and counts are fictional sample values. The seed serves these files from the API, so it needs no external image service.

- `fox.jpg`, `round.jpg`, `cat.jpg`, `long.jpg`, `office.jpg`, `korean.jpg`: ① ホーム（全体メイク） recipe cards
- `brow-*.jpg`: ③ 部位別一覧 brow styles, each a cell of Plan A's brow style sheet (`apps/mobile/assets/plan-a/parts/brow-styles.jpg`)
- `product-brow-pencil.jpg`, `product-cheek.jpg`: ⑤ レシピ詳細 使うメイク品
- `../sample-avatars/mio.png`: ⑤ author avatar

The team supplied these design assets or generated them with OpenAI or Google Gemini. See the [OpenAI terms](https://openai.com/policies/terms-of-use/) and [Google terms](https://policies.google.com/terms?hl=ja&gl=JP) for generated output.

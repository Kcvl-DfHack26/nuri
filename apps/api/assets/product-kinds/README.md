# Product kinds

Photos ⑤ shows beside a cosmetic published with a posted recipe (#224), one per kind, because the poster's own product has no photo in nuri. `productKindImage` in `@starter/shared` picks the file by the step's part; shading and highlight share one photo, and base has none.

- `brow.jpg`: eyebrow pencil (`eyeblow.png`)
- `eye.jpg`: eyeshadow palette (`eyeshadow.png`)
- `lash.jpg`: eyeliner (`eyeliner.png`)
- `cheek.jpg`: blush (`cheek.png`)
- `highlight-shading.jpg`: highlight and shading palette (`highlight_and_shading.png`)
- `lip.jpg`: lipstick (`rip.png`)

Provided by the team (kiyo-cmvs, 2026-11-09) as generic images without brands, cropped to a square and resized to 256 px. The images came from team-provided material or image generation. See the [source and terms for the sample recipe assets](../sample-recipes/README.md).

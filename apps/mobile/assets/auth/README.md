# 認証ボタンの公式素材

Googleのロゴは公式の[Branding guidelines](https://developers.google.com/identity/branding-guidelines)で配布される[Google G icon](https://developers.google.com/static/identity/images/g-logo.png)。元の多色・縦横比・白背景を維持する。ロゴを独自アイコンへ置き換えない。

AppleのiOSボタンはexpo-apple-authenticationのASAuthorizationAppleIDButton（Continue・Black）を使用する。Android/Webの画像は[Apple公式のボタン生成](https://appleid.cdn-apple.com/appleid/button?color=black&border=false&type=continue&width=280&height=48&locale=ja_JP&scale=3)の「Appleで続ける」をそのまま表示する。画像内のロゴ・文字・比率を変更しない。ログイン画面はPlan Aのライト配色だけなので、明るい背景とのコントラストを保つ黒を使う。

これらは認証提供元のブランド素材であり、このリポジトリ独自のロゴではない。[Appleのガイドライン](https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple)に従って認証ボタン内でのみ使用する。
